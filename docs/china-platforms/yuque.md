# 语雀接入方案

## 接入目标

- 支持语雀知识库与文档内容同步
- 首期聚焦“知识库 -> 文档列表 -> 文档正文”

## 鉴权与配置

### 凭证字段（建议）

- `access_token` 或 `client_id/client_secret`（按官方能力）
- `group_or_namespace`
- `book_id`（可选，空则按空间全量）

### 鉴权流程

1. 使用 token 或 OAuth 鉴权
2. 拉取知识库列表与文档列表
3. 文档详情接口获取正文（Markdown/HTML）

## 接口适配内容（计划）

### 结构发现

- 空间/知识库列表
- 知识库下文档目录树

### 内容拉取

- 文档详情（标题、正文、更新时间）
- 评论/附件（后续）

### 实体映射（MVP）

- `YuqueDocEntity`
  - 主键：文档 id
  - 字段：标题、body、book、path、更新时间、url

## 遇到的问题与风险

- 不同语雀版本/组织权限模型可能有差异
- 正文格式可能与 Airweave chunk 预处理存在兼容问题
- 大知识库全量同步时耗时与限流风险较高
