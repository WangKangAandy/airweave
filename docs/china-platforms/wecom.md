# 企业微信知识平台接入方案

## 接入目标

- 评估并接入企业微信侧可用的知识文档能力
- 以“可授权、可遍历、可读取正文”为首期验收标准

## 鉴权与配置

### 凭证字段（建议）

- `corp_id`
- `agent_id`
- `secret`
- `root_scope`（可选：部门/空间）

### 鉴权流程

1. 企业应用凭证换取 access token
2. 使用 token 调用知识/文档相关接口
3. token 失效自动刷新

## 接口适配内容（待确认）

### 结构发现

- 空间/目录/文档列表（按官方可用接口）

### 内容拉取

- 文档正文
- 文档元信息（作者、更新时间、链接）

### 实体映射（MVP 规划）

- `WecomDocEntity`
  - 主键：文档 id/token
  - 字段：标题、正文、路径、更新时间、url

## 遇到的问题与风险

- 企业微信开放能力模块化较强，文档能力可能依赖特定产品线
- 不同企业租户启用能力不同，存在“接口可用性不一致”
- 需提前定义“无正文能力”的可接受降级方案
